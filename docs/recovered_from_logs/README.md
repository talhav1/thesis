# Recovered evidence tables

Generated by `tools/reconstruct_from_logs.py` from the committed
`results/*.log` files (all present since commit `4747866`, "project init").
**Not a `results/` writer under the provenance contract** (CLAUDE.md §3, §6):
no experiment ran, no `run_id` was minted, nothing here is sanctioned by
`experiments/_runner.py`. It is a re-parse of console text a runner already
printed and that git already has, done to answer whether the claims in
`docs/claims.md` are checkable now that the underlying summary CSVs and raw
parquet are gone. See `docs/discrepancies.md` D22 for the full account.

## What this recovers, and what it can't

The `.log` files hold the pivot tables the pipeline printed to stdout on
completion — same numbers as the missing summary CSVs, at whatever rounding
the original `print(df.round(...))` call used (mostly 3–4 decimals). What they
do **not** hold:

- **Raw parquet / per-replicate rows.** Only the aggregated table survives.
  Any statistic not printed (e.g. per-replicate residuals) is gone for good.
- **MC standard errors beyond what was printed.** Where a log line includes an
  SE column (`coverage_se`, `false_certainty_se`, ...), it's here. Where the
  original summary CSV would have had additional SE columns not printed to
  the console, those are not recoverable.
- **`phase3b_screen` Block II.** `phase3b_screen.log` prints only "Block I,
  n=50, reference posterior" (the false-certainty and coverage crosstabs).
  Despite a Block II figure existing
  (`results/figures/phase3b_atlas_blockII_ref_n50.png`), no Block II table
  appears in the log. C6, C7, C10 rest partly on Block II per `docs/claims.md`
  and are only partially re-checkable from this recovery.
- **`phase1_table1_and_3_reproduction.csv`, `phase2_false_certainty.csv`,
  `phase2_coverage_map_stratified.csv`, `phase2_coverage_stratified.csv`,
  `phase3b_pseudo_truth.csv`** (full per-policy quantile table, as opposed to
  the spread-across-policies summary that *is* recovered). None of these
  tables were printed to any log; not recoverable from this source at all.
